# Τεκμηρίωση τύπων

Όλοι οι πίνακες διαβάζουν το `Log_Δραστηριότητας`. Καμία τιμή δεν γράφεται από
script — αν κάτι δείχνει λάθος, το λάθος είναι είτε στο ημερολόγιο είτε εδώ.

## Στήλες του ημερολογίου

| Στήλη | Περιεχόμενο | Χρήση σε τύπους |
|---|---|---|
| A | Χρονοσήμανση | — |
| B | Ημερομηνία γεγονότος | φιλτράρισμα περιόδου |
| C | Πηγή | ανάλυση ανά λίστα |
| D | Κανάλι (Τηλέφωνο / Μήνυμα) | ξεχωρίζει κλήσεις από μηνύματα |
| E | Κλειδί επαφής (φύλλο#γραμμή) | — |
| F | Όνομα | — |
| G, H | Παλιά / νέα κατάσταση | — |
| I | Ορόσημο | εγγυάται ότι κανένα ορόσημο δεν μετριέται δύο φορές |
| J | Γεγονός | το κύριο κριτήριο κάθε μετρητή |
| K | Στάδιο (1/2/3) | ξεχωρίζει 1ο, 2ο, 3ο ραντεβού |
| L | Ποσό (€) | παραγωγή |
| M | Σχόλιο | — |

Τιμές της στήλης J: `ΠΡΟΣΕΓΓΙΣΗ`, `ΕΠΑΦΗ`, `ΡΑΝΤΕΒΟΥ_ΚΛΕΙΣΤΟ`,
`ΡΑΝΤΕΒΟΥ_ΕΓΙΝΕ`, `ΣΥΜΒΟΛΑΙΟ`, `ΑΠΩΛΕΙΑ`, `ΑΚΥΡΩΣΗ`.

## Βασικά μοτίβα

**Μετρητής γεγονότος σε περίοδο** — η αρχή της περιόδου είναι σε κρυφό κελί:

```
=COUNTIFS(Log!$J$2:$J$20000,"ΠΡΟΣΕΓΓΙΣΗ",
          Log!$D$2:$D$20000,"Τηλέφωνο",
          Log!$B$2:$B$20000,">="&B$5)
```

**Άθροισμα παραγωγής:**

```
=SUMIFS(Log!$L$2:$L$20000, Log!$J$2:$J$20000,"ΣΥΜΒΟΛΑΙΟ",
        Log!$B$2:$B$20000,">="&B$5)
```

**Ημερήσια ανάλυση** — μία γραμμή ανά ημέρα και πηγή:

```
A2: =IFERROR(QUERY(Log!$B$2:$C$20000,
      "select B, C where B is not null group by B, C order by B",0),"")
C2: =ARRAYFORMULA(IF($A2:$A="","",COUNTIFS(...,Log!$B...,$A2:$A,Log!$C...,$B2:$B)))
```

**Αναλογίες** — καθαρές διαιρέσεις μεταξύ γραμμών όγκου, με `IFERROR` για το
μηδενικό ξεκίνημα:

| Δείκτης | Τύπος |
|---|---|
| Ποσοστό επαφής | επαφές ÷ κλήσεις |
| Ποσοστό ραντεβού | ραντεβού κλεισμένα ÷ επαφές |
| Ποσοστό εμφάνισης | ραντεβού που έγιναν ÷ ραντεβού κλεισμένα |
| Ποσοστό κλεισίματος | συμβόλαια ÷ ραντεβού που έγιναν |
| Κλήσεις ανά ραντεβού | κλήσεις ÷ ραντεβού κλεισμένα |
| Κλήσεις ανά συμβόλαιο | κλήσεις ÷ συμβόλαια |

**Απαιτούμενες κλήσεις/ημέρα:**

```
υπόλοιπο μήνα ÷ (παραγωγή ÷ κλήσεις) ÷ ημέρες που απομένουν
```

Χρησιμοποιεί το δικό σου ιστορικό «€ ανά κλήση» από τη στήλη «Συνολικά», όχι
υπόθεση. Όσο λίγα είναι τα δεδομένα, τόσο πιο ασταθής ο αριθμός.

## Παράθυρα περιόδου

| Παράθυρο | Αρχή |
|---|---|
| 7 ημέρες | `=TODAY()-6` |
| 30 ημέρες | `=TODAY()-29` |
| Μήνας μέχρι σήμερα | `=EOMONTH(TODAY(),-1)+1` |
| Συνολικά | `=DATE(2000,1,1)` |

Στον `Πίνακα Coach` προστίθεται και το παράθυρο «4 Ημέρες» (`=TODAY()-3`).

## Χαρτογράφηση στηλών του coach

| Στήλη coach | Πηγή |
|---|---|
| ΤΗΛΕΦΩΝΑ ΑΠΟ ΤΗΝ ΛΙΣΤΑ ΕΠΑΦΩΝ ΜΟΥ | ΠΡΟΣΕΓΓΙΣΗ, τηλέφωνο, πηγή = Προσωπικές επαφές |
| Cold Calls | ΠΡΟΣΕΓΓΙΣΗ, τηλέφωνο, πηγή ≠ Προσωπικές επαφές |
| Μηνύματα σε αγνώστους | ΠΡΟΣΕΓΓΙΣΗ, κανάλι μήνυμα |
| ΕΚΛΕΙΣΑ 1ο ΡΑΝΤΕΒΟΥ | ΡΑΝΤΕΒΟΥ_ΚΛΕΙΣΤΟ, στάδιο 1 |
| 1ο / 2ο / 3ο Ραντεβού | ΡΑΝΤΕΒΟΥ_ΕΓΙΝΕ, στάδιο 1 / 2 / 3 |
| Ραντέβου που πραγματοποίησα | ΡΑΝΤΕΒΟΥ_ΕΓΙΝΕ, όλα τα στάδια |
| Συμβόλαια που έκλεισα | ΣΥΜΒΟΛΑΙΟ |
| NVWP | άθροισμα ποσών συμβολαίων |
| Ερωτηματολόγια, μηνύματα σε γνώστους, follow-ups, λεπτά, συζητήσεις, δημοσιεύσεις, συστάσεις | **χειροκίνητα** — δεν προκύπτουν από αλλαγές κατάστασης |

## Όριο μεγέθους

Οι τύποι δείχνουν μέχρι τη γραμμή `20000` του ημερολογίου (σταθερά `LOG_LIMIT`
στο `Setup.gs`). Το φύλλο δημιουργείται με τόσες γραμμές. Αν γεμίσει, εμφανίζεται
προειδοποίηση: αύξησε τη σταθερά και ξανατρέξε το `setupAll`.
